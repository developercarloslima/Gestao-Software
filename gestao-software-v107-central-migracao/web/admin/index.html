PARA COLOCAR NO AR

O que falta para o endereço funcionar?

  1. Configure no DNS um registro wildcard ou o registro A do subdomínio apontando para o proxy.
  2. Instale o Traefik na VPS com certificados HTTPS válidos e publique as imagens homologadas dos módulos.
  3. Execute o agente autorizado e confira o status online. Conclua contrato e pagamento pela Implantação Guiada.
  4. Implante e valide o checklist no painel do cliente. A URL será liberada apenas após confirmação real pelo backend.

Domínio próprio do cliente: requer validação de titularidade e configuração DNS separada. Não é criado automaticamente nesta versão.
